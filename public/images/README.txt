HOW TO ADD PHOTOS
=================
Drop a .jpg file into this folder with the exact name shown on each card
on the website — the photo appears automatically, no code changes needed.
Recommended sizes: menu items 800x400 px, offer cards 800x380 px (landscape). JPG format.
